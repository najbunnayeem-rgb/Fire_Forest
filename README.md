Forest Fire Prediction Using Machine Learning
Project Overview
This project aims to predict the Fire Weather Index (FWI) using Machine Learning techniques.

The application takes environmental and weather-related input features and predicts the Fire Weather Index (FWI), which helps estimate the potential fire danger.

The project uses Python and Scikit-learn for model development and Flask to build a web application where users can enter input values and receive predictions.

Project Objectives

- Analyze weather and environmental data.
- Perform data preprocessing and exploratory data analysis (EDA).
- Train and evaluate Machine Learning regression models.
- Predict the Fire Weather Index (FWI).
- Deploy the trained model using a Flask web application.

Technologies Used

- Python – Programming language
- NumPy – Numerical computations
- Pandas – Data manipulation and analysis
- Matplotlib & Seaborn – Data visualization
- Scikit-learn – Machine Learning model development
- Flask – Web application development
- Pickle – Saving and loading trained models
- HTML & CSS – Frontend development
- Jupyter Notebook– Data analysis and experimentation
